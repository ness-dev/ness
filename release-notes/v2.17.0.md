- test: stop vitest from running compiled tests out of build output (#311)
- feat(sidebar): pinned worktrees section + Pin/Unpin action (#309)
- Show browser screenshots in the chat transcript (#303)
- feat(chat): drag the divider to resize the prompt box (#310)
- Improve diff visibility by brightening colors (#307)

- feat(editor): per-repo and per-worktree editor overrides (#306)
- Fix PWA Home Screen icon still showing the old Harness artwork (#302)
- Show "Ness" instead of "harness" in the macOS app menu (#300)
- Fix three renderer perf metrics that lied, and the bug they hid (#290)
- Stop browser evals from hanging a tool call forever (#299)
- Stop restored shell tabs from re-running their command (#292)

- Cut worktree-switch latency by capping and deferring git reads (#291)
- Stop worktrees flickering out of Needs Attention on UNKNOWN mergeability (#289)
- Add a setting to swap click / ⌘-click on terminal links (#286)
- site(chat-forking): HN thread link and reworded announcement summary (#287)

- Cap the context panel height and scroll its category list (#282)

### Installing

- **Apple Silicon:** `Ness-2.17.0-arm64.dmg`
- **Intel:** `Ness-2.17.0.dmg`

Drag `Ness.app` to Applications, then launch it. Existing installs will auto-update.
